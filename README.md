# Awesome-Video-Analysis

## Top Video Analysis (Sports)

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Sports Video Analysis, Tactical Analysis, Coaching, Performance Analysis & Athlete Development*  
**Last updated: August 2026**

This repository tracks notable **SaaS/hosted platforms** and **open-source projects** for **Sports Video Analysis**. These tools help coaches, analysts, teams, and athletes capture, tag, annotate, compare, measure, and analyze sports video to improve tactical understanding, technical execution, player development, and performance.

**Examples** include Hudl, Dartfish, Nacsport, Coach Paint, Spiideo, Catapult Vision, LongoMatch, Kinovea, Hudl Sportscode, and Performa Sports.

**Open-source emphasis**: This section is heavily expanded with open-source sports-video analysis applications, computer-vision projects, video annotation tools, motion-analysis software, tracking frameworks, and sports analytics libraries. Kinovea is a particularly strong open-source option for capture, annotation, comparison, tracking, and measurement, while LongoMatch is specifically oriented toward tagging and analyzing sports plays.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.
